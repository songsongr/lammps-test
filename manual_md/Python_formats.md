# [2.7. ]{.section-number}Output Readers[](#module-lammps.formats "Link to this heading"){.headerlink}

The Python package contains the [[`lammps.formats`{.xref .py .py-mod .docutils .literal .notranslate}]{.pre}](#module-lammps.formats "lammps.formats"){.reference .internal} module, which provides classes to post-process some of the output files generated by LAMMPS.

Output formats for LAMMPS python module Written by Richard Berger \<[richard.berger@outlook.com](mailto:richard.berger%40outlook.com){.reference .external}\> and Axel Kohlmeyer \<[akohlmey@gmail.com](mailto:akohlmey%40gmail.com){.reference .external}\>

*[[class]{.pre}]{.k}[ ]{.w}*[[lammps.formats.]{.pre}]{.sig-prename .descclassname}[[LogFile]{.pre}]{.sig-name .descname}[(]{.sig-paren}*[[filename]{.pre}]{.n}*[)]{.sig-paren}

:   Reads LAMMPS log files and extracts the thermo information

    It supports the line, multi, and yaml thermo output styles.

    Parameters[:]{.colon}

    :   **filename** (*str*) -- path to log file

    Variables[:]{.colon}

    :   - **runs** -- List of LAMMPS runs in log file. Each run is a dictionary with thermo fields as keys, storing the values over time

        - **errors** -- List of error lines in log file

<!-- -->

*[[class]{.pre}]{.k}[ ]{.w}*[[lammps.formats.]{.pre}]{.sig-prename .descclassname}[[AvgChunkFile]{.pre}]{.sig-name .descname}[(]{.sig-paren}*[[filename]{.pre}]{.n}*[)]{.sig-paren}

:   Reads files generated by fix ave/chunk

    Parameters[:]{.colon}

    :   **filename** (*str*) -- path to ave/chunk file

    Variables[:]{.colon}

    :   - **timesteps** -- List of timesteps stored in file

        - **total_count** -- total count over time

        - **chunks** -- List of chunks. Each chunk is a dictionary containing its ID, the coordinates, and the averaged quantities
