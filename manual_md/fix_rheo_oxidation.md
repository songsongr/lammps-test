# fix rheo/oxidation command[](#fix-rheo-oxidation-command "Link to this heading"){.headerlink}

::::: {#syntax .section}
## Syntax[](#syntax "Link to this heading"){.headerlink}

:::: {.highlight-none .notranslate}
::: highlight
    fix ID group-ID rheo/oxidation cut btype rsurf
:::
::::

- ID, group-ID are documented in [[fix]{.doc}]fix.md){.reference .internal} command

- rheo/oxidation = style name of this fix command

- cut = maximum bond length (distance units)

- btype = type of bonds created

- rsurf = distance from surface to create bonds (distance units)
:::::

:::: {#description .section}
## Description[](#description "Link to this heading"){.headerlink}

::: versionadded
[Added in version 29Aug2024.]{.versionmodified .added}
:::

This fix dynamically creates bonds on the surface of fluids to represent physical processes such as oxidation. It is intended for use with bond style [[bond rheo/shell]{.doc}]bond_rheo_shell.md){.reference .internal}.

Every timestep, particles check neighbors within a distance of *cut*. This distance must be smaller than the kernel length defined in [[fix rheo]{.doc}]fix_rheo.md){.reference .internal}. Bonds of type *btype* are created between a fluid particle and either a fluid or solid neighbor. The fluid particles must also be on the fluid surface, or within a distance of *rsurf* from the surface. This process is further described in [[(Clemmer)]{.std .std-ref}](#howto-rheo-clemmer2){.reference .internal}.

If used in conjunction with solid bodies, such as those generated by the *react* option of [[fix rheo/thermal]{.doc}]fix_rheo_thermal.md){.reference .internal}, it is recommended to use a [[hybrid bond style]{.doc}]bond_hybrid.md){.reference .internal} with different bond types for solid and oxide bonds.

## Restart, fix_modify, output, run start/stop, minimize info[](#restart-fix-modify-output-run-start-stop-minimize-info "Link to this heading"){.headerlink}

No information about this fix is written to [[binary restart files]{.doc}]restart.md){.reference .internal}. None of the [[fix_modify]{.doc}]fix_modify.md){.reference .internal} options are relevant to this fix. No global or per-atom quantities are stored by this fix for access by various [[output commands]{.doc}]Howto_output.md){.reference .internal}. No parameter of this fix can be used with the *start/stop* keywords of the [[run]{.doc}]run.md){.reference .internal} command. This fix is not invoked during [[energy minimization]{.doc}]minimize.md){.reference .internal}.
:::

::: {#restrictions .section}
## Restrictions[](#restrictions "Link to this heading"){.headerlink}

This fix must be used with the bond style [[rheo/shell]{.doc}]bond_rheo_shell.md){.reference .internal} and [[fix rheo]{.doc}]fix_rheo.md){.reference .internal} with surface detection enabled.

This fix is part of the RHEO package. It is only enabled if LAMMPS was built with that package. See the [[Build package]{.doc}]Build_package.md){.reference .internal} page for more info.
:::
